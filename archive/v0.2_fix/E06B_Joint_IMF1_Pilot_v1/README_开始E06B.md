# E06-B | 冻结联合MVMD后的双路共享细节去噪：一次性可行性试验

## 为什么做
E06-A实测Z3-1和Z3-2动态侧带均被99.3%+保留，先前“硬保护被误删侧带”假设不成立。为确保研究继续靠近真正的FVIM-MVMD改进，本轮**仅尝试在已经保留的IMF1上进行两路联合共享权重Haar小波细节抑噪**，同时不破坏已证实保留良好的1~5Hz动态有效分量。它是**候选改进**，不预称创新成功。

## 需要已有文件
在之前E06-A工程目录下，运行成功后保留 `results_E06A/Z3-1/E06_record.mat` 和 `results_E06A/Z3-2/E06_record.mat`（E06-A程序自动保存过）。本实验不需要重新运行E06-A的MVMD分解。

## 操作
1. 解压本工程。
2. 打开 `E06B_config.m`，把 `cfg.previousResults` 修改为已有 `results_E06A` 文件夹的绝对路径；其他固定参数先不要改。
3. MATLAB 当前目录设为本工程，运行：
   ```matlab
   E06B_run
   ```
4. 上传 `results_E06B/E06B_quality.csv`, `E06B_sidebands.csv`, `E06B_decision.txt`, `E06B_spectrum_preview_Z3-1.png`。

## 核心机制
- 当前双通道联合MVMD已分解好的第1模态 `modes(:,:,1)` 两路同时处理；
- 正交Haar变换，对每个时间-尺度位置a/s一对细节系数，**使用同一个联合幅值和收缩权重**；
- 仅处理小波细节1~6级（采样率1kHz时粗略>=7.8Hz），低频近似层不动；这不等于理想砖墙低通，最终以实测侧带幅相为准。
- 使用第1级双通道pooled MAD自动估计噪声尺度，固定阈值倍率0.75；**不使用转台真值、不读验证侧带频率进行滤波**，仅用于评价。
- 候选 = 已有冻结MVMD重构 + (联合新IMF1 - 原IMF1)，其他模态均保持一致。

## 一次实验的“停/走”准则
- Z3-1(2、4Hz)、Z3-2(1、5Hz)两个通道：候选相对原始幅值至少保留99%，相对原始边带相位偏移绝对值<=0.2°。
- 两个案例、两条通道的*非目标谐波残差RMS代理*相对原冻结MVMD进一步降低至少1dB。
- **两条件同时达到**才值得后续独立数据/姿态精度验证。任一失败，停止此项，不通过反复调参数创造有利结果。

## 实验边界
这个新方法是对IMF1的**联合小波后处理候选**；它不是在本轮重新执行FVIM参数寻优，不要把它称为完成的改进FVIM-MVMD。噪声代理不是干净真值SNR；本实验也不提供真实姿态角RMSE。无MATLAB运行环境时，用户需自行实机验证。
