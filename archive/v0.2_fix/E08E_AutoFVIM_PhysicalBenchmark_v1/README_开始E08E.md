# E08-E：FVIM 自主寻优 vs 固定强基准——真实双正交陀螺统一对照

**研究主线**：在每档已知滚转频率下使用已预标定的零偏、复标度，优化的只有 MVMD 的模态数 K 和惩罚系数 α。不估计在线零偏，不学习真值角速度，也不动态估计滚转频率。

> 本工程使用先前 E08-C 的四领先者 **FVIM 风格工程复现**，不是 FVIM 论文原作者源码的逐行复现。原版算法已找到 MathWorks File Exchange 发布页，正式论文前应核实算法更新公式并替换/设置原版对照。不能将本版本在论文中无条件称作“原版 FVIM”。

## 1. 与上一轮相比，这次做了什么

E08-C/E08-D 在训练工况优化后，保存每档频率 K/α 参数，做可行性检查。E08-E 则**不读取任何 K/α 频率参数表**，而是在当前输入段上现场发起小预算自动搜索。同样的搜索边界、种子和计算预算，比较：

1. Raw：原始数据（不滤波）；
2. Fixed：K=8, α=154.157959862（固定强基准，但以前在9/12Hz有不收敛历史）；
3. Entropy Auto：以双通道 IMF 包络熵代理为目标的 FVIM 风格搜索；
4. Physics Auto：在两通道幅相、载波及动态边带约束下寻优的 FVIM 风格搜索。

**4种方法都采用同一种旧硬模态重构（CS/SampEn分类＋混叠Haar降噪）。** 这次隔离优化器/目标函数贡献，故不把 E07-D 软重构并进来。旧方案“硬分类跨1.8跳变”的问题仍然存在，待后续独立改进。

## 3. 自动优化如何执行（重要）

- 每个频率使用 **4组提前登记的共同起始候选**：`(8,154.157959862)`,`(6,185.0015)`,`(7,250)`,`(8,320)`。这只是搜索初始化，绝不是按频率查询最优参数。
- 旧熵目标额外主动产生4个候选；新物理目标额外主动产生4个候选。总计**最多12个唯一(K,α)组合/频率，24次训练 MVMD 求解/频率**（每候选需W/Z两组数据）。相同候选共用缓存，同一次分解同时评两套适应度，但两个算法仅从自己的4个初始候选+自己提出的4个候选中选赢家。
- 旧熵目标：只要求MVMD数值有效；新的物理目标：还必须同时满足双路保真和非负噪声代理改善，保持原先99～101%幅值、0.2°相位门槛。两者都报告未通过者，不隐藏失败。
- 自动寻优只读取W/Z训练段第4和第7列、已知f；不读取测试文件，不能用转台参考角速度给适应度打分。
- 搜索边界 K=5～9，α=80～450；滚转频率引导初始化；迭代上限1200、原收敛标准不改变。随机种子固定20261026。
- 训练窗口偏移0.5s，最多3.2s；测试使用后段约60%～95%范围中最多3s；严格分别记录数据文件来源。样本率默认1000Hz。

## 4. 固定标定如何使用

- 标定表提供各滚转频率固定的 `biasA`, `biasS`, `scaleACos`, `scaleASin`, `scaleSCos`, `scaleSSin`；程序不进行在线估计或在测试文件中重拟合这些系数。
- W类统一用E类零输入谐波基线 `HE`，与 E08-A 的 **`E08A_estimate_outer.m`** 一致，校正输出称 **有符号外框等效角速度**，不是机体系完整 Ωx/Ωy 或姿态角。
- W类的外框编码器第1列只作标签计算 `referenceOuterDegS`，内框第3列用于已知频率模型的初始相位/方向初始化；这些都不参与FVIM参数优化。这不是无编码器自主滚转相位估计。
- Z类尚不以外框恒速参考计算RMSE，只评价预先定义的载波/动态边带及双通道噪声代理，不能编造Z类角速度真值。
- `noiseProxyA_dB/noiseProxyS_dB` 为单频+边带拟合残差代理，**不是有干净参考的真实信噪比**。

| 结果文件 | 检查问题 |
|---|---|
| `results_E08E_9Hz/E08E_train_solver.csv` | 每组MVMD求解是否收敛、迭代次数、AC重构损失、耗时 |
| `E08E_train_candidates.csv` | 旧/新目标在**同一候选上两套打分**，区分数值可行与物理可行 |

| `E08E_test_metrics.csv` | 各方法幅相保真/代理，W类真实外框等效RMSE、MAE；失败为NaN而非删行 |

| `E08E_rate_W9_60_TXT.png` | W类曲线参考对照 |
| `E08E_status.csv` | 数据缺失、方法失败的明确记录 |
| `E08E_decision.txt` | 客观总结，非自动科研结论 |
| `E08E_paired_summary.csv` | 仅对同一文件两方法均有效的结果计算成对RMSE改善，另报数值失败率 |

建议先上传前6个CSV和 `E08E_decision.txt`。控制台显示 PASS 仅表明**合成自检**通过，不能冒充真实数据结果。

## 6. 两条研究路线的推进/转向规则

**路线A（首选）**：如果自动物理目标在9Hz同时收敛、保真，且在W9-60上角速度RMSE优于可用的强基准（若K8固定基准失败则必须与收敛的旧熵方法及其他已冻结强基准比），继续扩展3、12Hz并做重复种子可靠性检查。比较必须同文件、同标定，报告数值失败率，不仅报告成功者中的平均RMSE。

**路线B（保底）**：如果多频率自动寻优在求解器合理修复、共同预算公平比较和独立评价后，仍无法稳定取得有效增益，就停止把 K/α 在线或分段自动优化作为创新目标，退到经预先验证的参数＋双通道稳定模态重构改进，再推进角速度/姿态精度。**不默认K8/154在全部频率均有效。**

**注意**：目前仍使用小预算 FVIM 风格的代理搜索。若准备将其写成FVIM新算法，必须核对原作者论文更新方程和公开 MATLAB 源码，确认优化器实现的真实性；不能依赖“有四个领先者”这一个特征自行命名为原版FVIM。
