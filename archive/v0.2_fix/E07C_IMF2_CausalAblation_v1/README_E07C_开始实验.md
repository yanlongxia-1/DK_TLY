# E07-C：IMF2 硬阈值分类跳变的固定分解交叉消融

## 为什么开展
在 E07-B 的真实 Z3-1 中，K=8、alpha=292.9731 与 306.1287 具有接近的 IMF2 中心频率和能量，但 SampEn 分别为 1.793180 / 1.815064，跨过冻结阈值 1.8，导致前者 IMF2 混叠小波处理、后者直接丢弃；先前非目标残差代理相差约 3 dB。

本实验**不是另一轮参数寻优**，而是检查这个差异是否来自最终分类，而非 MVMD 模态本身。

## 操作
1. 解压后进入工程根目录，完整保留 inputs 子文件夹。
2. 在 MATLAB 命令窗口执行：`E07C_run`
3. 程序只读取 inputs/Z3-1_E06B_record.mat。两组alpha各联合分解一次，每组在**不改变分解**的条件下执行「IMF2混叠小波」「IMF2丢弃」两种重构。
4. 运行后提交 results_E07C 中：
   - `E07C_cross_reconstruction.csv`：两alpha×两策略的双路评价。
   - `E07C_IMF2_causal_delta.csv`：同一分解下改变分类产生的收益。
   - `E07C_same_policy_alpha_delta.csv`：同一重构策略下改变alpha产生的收益。
   - `E07C_decision.txt`：解释边界与下一步。
   - 如遇分类不一致，提交 MATLAB完整报错，不要修改 threshold 来强行通过。

## 注意
- 本实验只有2次 MVMD 求解，K=8、alpha=292.9731或306.1287、最多1200迭代，绝不运行FVIM大规模优化。
- E07B_config.m、gyro_mvmd.m、gyro_reconstruct.m、gyro_haar.m 均保持旧版原样。
- 只使用已见过的 Z3-1 TRAIN 数据。结果是作用机制诊断，**不是独立验证**，不能写成性能提升的论文结论。
- 不得把非目标谐波残差代理当作有真实干净信号参照的 SNR。
- 若分类跳变得到证实，下一步在训练集尝试对**一对双通道模态**设置连续保留权重，统一验证真实动态边带，不是重新发明静态零偏/滚转角求解。
