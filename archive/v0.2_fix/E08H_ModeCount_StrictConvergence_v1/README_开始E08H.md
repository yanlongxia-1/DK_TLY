# E08-H：模态数冗余假设的严格收敛验证（开发实验）

## 为什么安排 E08-H

E08-G真实实验已经证明：

- W9-60、K8/154.158、K7/450、K8/320 在 eta=1 或 eta=0.5，最多2400次都没有满足严格收敛。
- 阻尼 eta=0.5 不改善 W9-60，Z9-3反而让部分参数收敛更慢。**因此本轮恢复 eta=1**，不扫描阻尼。
- 在 W9-60，K8/154.158、eta=1、第2400次：IMF2（中心8.99Hz）占98.87%能量、44.51%变化；IMF3（12.52Hz）占0.385%能量、53.99%变化。另两个参数下 IMF3 同样贡献约51%的更新变化。
- 低能量IMF3可能包含真实运动边带，**不能直接删除，也不能放宽 tol 将未收敛快照当作有效解**。

因此，本实验**固定求解器更新方程、eta=1、tol=1e-5、AC重构门限0.15、最大迭代2400**，只做预登记的模态数 K 比较，检验是否存在过分解冗余。此轮**不是FVIM寻优、不是算法最终成果、没有新增盲测**。

## 训练、开发数据与预算

| 阶段 | 文件 | 用途 |
|---|---|---|
| 训练 | `W9-10.TXT` | 9Hz恒速双通道载波保真 |
| 训练 | `Z9-1.TXT` | 9±1Hz动态边带保真 |
| 开发复核 | `W9-60.TXT` | 已经反复查看过的非收敛难例，**非盲测** |
| 开发复核 | `Z9-3.TXT` | 已经查看过的动态难例，**非盲测** |

训练候选 K={3,4,5,6,7,8}、alpha={154.157959862,320}，最多24次训练MVMD（2文件×12参数）。严格锁定并选出训练候选之后，对两份开发文件分别运行选中候选和两组既有基准，最多6次求解。**最大30次分解；无大规模连续搜索，不会无限加迭代。**

窗口规则与 E08-G 一致：跳过前0.5秒，在95%文件时间之前取尾段最多3000点；至少2000点。`Z9-1`检查8、9、10 Hz；`Z9-3`检查6、9、12 Hz。数据列4和7为a、s；采样率1000Hz。

## 训练选参规则（运行前已经锁定）

对每组 `(K,alpha)`，要求**两份训练文件同时满足**：

1. 2400次以内严格收敛（模态变化量<1e-5、未阻尼中心目标差<0.01Hz、连续3次）；
2. AC重构误差<=15%；
3. 同源双通道硬重构：载波及动态边带的幅值保持 **99%～101%**，有效点相位变化 **<=0.2°**，双通道相对相位变化 **<=0.2°**；
4. 在上述条件满足时才根据已有`E07D_score`双通道物理代理得分选最小值。这个代理不是编码器真值、不是测量精度 RMSE。

不满足任一约束的参数设为不可行，**不会因低噪声代理分数而入选**。如果所有参数都不满足，明确给出无合格候选，不允许从 `W9-60` 的结果反向选 K。两个开发文件已被多轮查看，不能再当作独立验证。

## 操作

1. 解压完整工程，在MATLAB把当前目录切换到工程根目录。
2. 打开 `E08H_config.m`，仅修改 `cfg.dataRoot` 为包含上述四份TXT的真实根目录，支持子目录递归查询。
3. 先执行：

```matlab
E08H_selftest
```

4. 然后执行：

```matlab
E08H_run
```

结果保存在 `results_E08H`，中间不断存CSV：

- `E08H_cases.csv`: 每次求解器严格收敛/AC/保真/得分/能量主模态/最多迭代与错误信息；
- `E08H_training_selection.csv`: 两文件训练联合可行性，筛选出的最佳参数以 `meanScore` 最低定义；
- `E08H_decision.txt`: 是否真正产生两工况都合格的参数，明确开发集仅用于复核；
- `E08H_config_frozen.mat`: 完整配置和训练锁定候选；
- `E08H_issues.csv`: 文件缺失或读取错误时才存在。

注意：`E08H_cases.csv` 中的开发结果仅是诊断，不是新的独立测试；也**没有**直接输出角速度RMSE或姿态RMSE。

## 下一步的预定判断

- 若小K在训练及已看难例上均满足严格收敛、幅相保真，再把**约束K冗余/双通道边带保持**加入FVIM适应度并公平复跑，最终使用另外未参与开发的数据检验实测角速度RMSE。
- 若小K虽收敛却损伤8/10或6/12Hz动态边带，判定“仅缩小K不足以解决”，继续分析主载波/边带联合求解的稳定化，不直接丢掉IMF3。
- 若所有小K仍不收敛：停止本轮K扫描，下一阶段研究保留物理输出与完整重构残差的双层停止规则，必须将它与原全局严格收敛状态分别报告。

**严谨性声明**：本轮为模态数机理消融，既不调用原始FVIM元启发式，也不宣称找到跨频率通用最优参数。适应度使用现有工程物理代理，不读取编码器真值，也不动态标定偏置/标度因数。所有真实TXT必须在用户本地MATLAB运行，当前打包环境没有MATLAB运行时。
