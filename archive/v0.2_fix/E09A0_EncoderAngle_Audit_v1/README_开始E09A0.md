# E09-A0：真实外框编码器角度与积分角度对照（E09-A第一步）

## 本次必须验证的问题
E08-K中，W9-60角速度RMSE从3.24788降至3.18047 deg/s，但我们用E08K_series的恒定拟合转速积分，发现角度RMSE（相对线性参考）从0.14137°升至0.15262°。这个结果不能代替对**逐时刻真实编码器角度**的比较。E09-A0将直接读取历史TXT第1列外框角度、精确时间对齐E08-K输出，统一初始角度后积分，输出真实参考角度误差。

## 输入
- 原始`W9-60.TXT`（7列，第1列按已核定为外框**角度**，不要误当角速度；头行一个整数且符合ceil(rows/100)）。
- E08-K已生成的`E08K_series_W9_60_TXT.csv`（time_s、reference_outer_deg_s、raw、developer_K5、physics_auto），不重新计算MVMD和FVIM。
- 系统采样率名义1000Hz。时间索引：原始行号`round(time_s*1000)+1`，严格检查连续性、范围与对齐。

## 运行（仅修改路径，无需改算法参数）
1. 将本目录放到既有研究工程旁边，或者独立存放。
2. 打开`E09A0_config.m`，把`cfg.dataRoot`设置成真实TXT总目录；把`cfg.rateCsv`改成你实际的E08-K结果路径。
3. MATLAB切换到本目录并执行：

```matlab
E09A0_selftest
E09A0_run
```

输出：`results_E09A0/E09A0_encoder_angle_metrics.csv`、`E09A0_encoder_angle_series.csv`、`E09A0_angle_comparison.png`、`E09A0_scope.txt`。

## 评价定义
- `RMSE_encoder_deg`：积分角度减去**逐时刻外框编码器角度**的RMSE。首次样本对齐，不能利用后续编码器反向修正偏置或去趋势。
- `RMSE_fitted_deg`：积分角度减去拟合匀速参考积分角度的RMSE，仅对照旧阶段的初步积分结果。
- `EndError_encoder_deg`：评价段末端的编码器角度误差。注意初始角度对齐不是陀螺独立确定的绝对角度。

## 严格边界
1. 此试验仅用于外框等效单自由度的角度积分与误差传播分析，**不是**机体横向Ωx、Ωy的完整解调，也**不是**俯仰/偏航角RMSE。
2. 完整E09-A还需确认三框转台轴定义、旋转顺序、零位、传感器安装姿态，以及两个横向轴的灵敏度映射。现有W类单方向等效复标度，不能未经证明直接当完整双轴响应矩阵。
3. W9-60已用于开发，不是独立盲测。测试区间结果不得反向修改FVIM、校准、滤波或对齐规则。
4. 不需要叠加其他滤波器；优先验证已经存在的算法输出能否改善真实角度。
5. MATLAB自检脚本使用合成角度校验索引和积分行为；当前交付前未具备MATLAB实机运行条件，请先通过自检再运行真实数据。
