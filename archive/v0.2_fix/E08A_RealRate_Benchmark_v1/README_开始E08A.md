# E08-A｜固定标定下的真实 W 类外框等效角速度对照（2026-10-26）

## 本实验直接服务的研究主线

双正交无驱动 MEMS 陀螺仪：真实第4列 a、第7列 s → 同工况预标定参数 → 原始 / FVIM-MVMD 工程基准 / 双路物理目标＋软重构 → 有符号外框**等效**角速度测量误差；随后扩展至 Ωx/Ωy 和姿态角。

本次 **不是** 在线滚转角估计，不是动态零偏或动态标度因数研究，也不是 FVIM 重新寻优。本次任务是检验 E07-D 训练时降噪代理的改善是否传递为 **真实传感器的角速度误差降低**。对 E07-D 结果未达标，应先区分固定标定误差与滤波误差，再决定是改进联合权重还是适应度函数。

## 使用之前必须具备

提供完整 `20200824` TXT 文件目录，至少包含 `W6-20.TXT`、`W9-20.TXT`、`E6.TXT`、`E9.TXT`。**这些文件没有包含在实验包**。不可用 E07-D 留出表替代原始采样点，不可从只有 W3-20 的历史图表推算两组结果。

CSV `calibration_final.csv` 已内置并且用于查找每一滚转频率的E类偏置和两路复响应系数。`E07D_locked_params.csv` 已内置，原优化轨迹选取旧目标K6 α185.0015、新目标K8 α154.158。均不得对W6/W9重新调参。

## 运行

1. 解压项目，不覆盖旧 E05/E07-D 工程。
2. 打开 `E08A_config.m`，把 `cfg.dataRoot` 指向包含全部 TXT 的顶层数据目录（递归扫描），例如：

```matlab
cfg.dataRoot = 'E:\dak_data\Desktop\实验\jyk_Test\20200824';
```

如果你的真实数据位于其他路径，以实际路径为准。

3. MATLAB 将当前目录切换到本项目根目录，运行：

```matlab
E08A_selftest
E08A_run
```

主入口会自动再执行一次自检。默认计算W6-20与W9-20（每文件最多3个不同K/α联合分解，加一次硬重构与软重构，不做新的FVIM搜索）。如果共同池候选K9 α450不需要，可将`cfg.methods.entropyPoolDiagnostic=false`，每文件只需2次联合分解。MVMD采用完整评价数据块的离线分解，**非因果算法，不能直接宣称能够实时上板**。

## 严格固定的四种主对照

| 方法 | 参数 | 重构 | 实际含义 |
|---|---|---|---|
| raw | — | — | 原始通道，不滤波 |
| frozen_hard | K8 α154.158 | 硬 CS＋SampEn | 先前强基线；与本次新目标选参的硬重构等效 |
| entropy_hard | K6 α185.0015 | 硬重构 | E07-D **旧目标优化轨迹**选中结果，不是全局最优 |
| joint_soft | K8 α154.158 | 共享双通道连续权重 | E07-D 提议的新方法 |
| pool_entropy_hard | K9 α450 | 硬重构 | **可选**共同20候选池熵最优诊断，不是另一次完整FVIM搜索 |

实验只比较已存在的配置，不能根据此处W6/W9 RMSE再次调参再称独立验证。

## 物理建模与数据使用边界

- 原始7列：1外框**角度**、2中框**角度**、3内框**角度**、4 a、6加速度计、7 s；首行整数是块计数头，不能作为采样点。
- W类标度是基于外框角度实测斜率与 E6/E9 零输入谐波差构造的**外框等效轴复响应**，非一般机体 Ωx/Ωy 标定。
- 通过 `y=b_E + H_E·[cosθ,sinθ] + Ω_outer·K_eq·[cosθ,sinθ]` 的双路最小二乘恢复有符号外框等效角速度。其中 H_E 为独立 E 类纯滚转数据的谐波系数；不能将H=C+iS直接用复数除法作为角速度。
- 主报告用已知 f_roll 与已知台架初相位（默认来自第3列第一采样）和滚转方向构建固定相位 `θ(t)=θ0 ± 360 f_roll t`。这是**台架辅助初始化**，不是在线滚转角估计。`RMSE_encoderPhaseDiagnostic` 另使用全段内框编码器真实角度，为相位误差的离线诊断上界，不能作为实际可用的自主方案。
- 外框真值只在**评价**时使用：把第1列展开后在评价段拟合斜率作为恒定参考角速度；不参与滤波参数、零偏、标度或每文件额外校正。
- 零偏采用同频率E类预标定偏置，保留W类工况截距未补偿的系统误差，所有方案处理方式完全一致。本轮不使用已知台架20deg/s推导额外有效截距。
- `W6-20` 已在E07-D被查看过，不能称新盲测；`W9-20` 也应核实先前是否已经参与过任何算法决策。
- 固定采样率1000Hz是本数据集的近似名义值；如编码器显示漂移，需在报告明确其影响。

## 输出

每个W工况单独保存到 `results_E08A/W6-20/`、`results_E08A/W9-20/`：

- `E08A_solver.csv`：每个不同K/α求解器的实际收敛情况。
- `E08A_rate_metrics.csv`：核心结果：**固定频率相位的有符号外框等效角速度** RMSE / MAE / 平均误差 / STD；以及编码器实际相位的离线诊断RMSE、幅相保持和单频SNR代理增益。
- `E08A_rate_series.csv`：逐点等效角速度/参考真值时序；`E08A_rate_compare.png`：时域波形对照。
- `modes_*.csv`：每个分解的 IMF 分类和共享软权重（同时输出硬/软细节）。
- `E08A_record.mat`：滤波输出、完整评价时序、复标度和E类零输入谐波等用于后续接姿态解算的数据。
- `E08A_interpretation.txt`：含真实参考适用范围和非因果实现说明。

根目录 `results_E08A/E08A_summary.csv` 汇总所有成功案例；`E08A_status.csv` 记录失败文件及信息。如果缺少数据，**程序明确报缺少文件，不会输出虚构的角速度RMSE**。

## 实验验收与研究决策

1. 先检查 `E08A_solver.csv` 的 `converged=1`、`valid=1`；非收敛方法不进入量化结论。
2. 确保各滤波方案使用**完全相同评价区间、固定标定、滚转频率、台架相位初始化**。
3. 检查幅值保持、相位变化和等效角速度RMSE是否同时改善。**不能将单频SNR代理当成干净真值SNR，也不能用外框等效轴RMSE替代机体Ωx/Ωy或最终俯仰/偏航角RMSE。**
4. 若 joint_soft 没有优于 frozen_hard，应该利用 E07-D 四格消融发现的软重构失利现象，对其连续权重进行有依据的修改和再训练；**不因一次失败直接放弃创新方向**，也不能利用本次评价工况反向重调权重后再叫盲测。
5. 若新算法跨工况稳定改善，则锁定算法并推进下一阶段：多轴双正交角速度反演（确认转台轴系/安装符号）与俯仰/偏航角误差验证。
