# E08-F｜MVMD 收敛轨迹与 Z9-3 截窗审计（不重新FVIM寻优）

## 实验原因

E08-E 在 W9-10 与 Z9-1 训练段的12组不同候选全部可行，但在 W9-60 评估段，固定 K8/154.158、旧熵 K7/450、新物理 K8/320 三组都达到1200迭代上限且没有通过严格收敛；AC误差仅0.26%、0.72%、0.46%，并不是重构误差阈值超限。Z9-3 因原截窗 `round(.60*N)` 至 `round(.95*N)`（最多3秒），再要求 >=2秒，未进入滤波阶段。并不能据此判断 Z9-3 原始文件本身不足2秒。

## 运行

1. 解压此独立工程。`lib` 附带 E08-E 使用的原版 `gyro_mvmd_conditioned.m` 和 `read_gyro_txt.m`，保持求解公式和阈值不变。
2. 打开 `E08F_config.m`，确保 `cfg.dataRoot` 对应包含全部 TXT 的目录。
3. 在 MATLAB 将当前文件夹切换到本工程，运行：

```matlab
E08F_run
```

不需要重做E08-E搜索。每个合法窗口上只复核三组**已经锁定**的候选，不以W9-60 / Z9-3反向选择最优K、alpha。先保留完全一样的 `tol=1e-5`、频率引导初始化和 `tau=0`，最大迭代2400只用于收敛轨迹诊断，**不表示正式实验放宽要求**。

## 设计：两种同一预登记的窗口逻辑

- `legacy_60to95`：E08-E 原始的60%到95%段，最多3秒，若少于2秒直接记录跳过。
- `tail_last3s`：从排除前0.5秒后的有效区间截至95%时刻，截取末尾最多3秒；当原始文件足够长时，有利于检查旧截窗是否无谓丢弃有效数据。**这两个窗口不作为互换使用的测试集，也不允许挑选结果更好的一个去写最终论文。**

## 输出

- `results_E08F/E08F_windows.csv`：两文件原始总样本数和两种窗口的起止索引、时长，可直接判断Z9-3失败原因。
- `E08F_solver.csv`：三组锁定参数在不同窗口、2400迭代诊断预算下的收敛状态、最终误差及第1200次变化量。`convergedBy1200` 和 `solverValidAt2400` 严格区别。
- `E08F_trajectory.csv`：第100、200、400、…、2400次的 `delta`、`centerDeltaHz`、频域残差与瞬时阈值通过状态，分析是否继续下降还是出现平台/震荡。
- `E08F_issues.csv`：数据或求解错误（仅异常时生成）。
- `E08F_config_frozen.mat`：固定配置存档。
- `E08F_说明.txt`：实验边界和后续正确的复现方式。

## 结束后的研究决策

1. 如三组中至少部分在1200～2400次达到原严格收敛标准，说明原有1200上限在部分高幅度工况下不够。之后需在**训练文件**上统一确定正式迭代预算，重新跑A/B/C公平比较，且重新保留真正未参与开发的测试文件。
2. 如2400后均未通过，检查 `delta` 是否持续下降、中心频率是否不稳定，再研究不改变物理约束的求解器修复（模态竞争、更新顺序、数值稳定性、终止策略）并在训练工况上测试；不要在W9-60上优化K、alpha让结果看起来更好。
3. 若Z9-3尾段超过2秒，下一次正式评价应**事先统一规定截窗方式**后重做所有方法和需要的训练，不可只为Z9-3例外地改段。
4. 通过数值稳定性后才比较角速度 RMSE，且要与收敛的强基准比较；原始W9-60的9Hz周期性角速度误差也应单独记录（滤波不会自动解决标定/解调的全部系统误差）。

> 当前工程已进行文件和静态检查，**没有在本环境执行MATLAB实机测试**。由于未提供W9-60 / Z9-3的原始TXT文件，无法在此计算新收敛曲线。
