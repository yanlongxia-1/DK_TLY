# E07-D：双通道连续模态重构 + FVIM式多目标联合寻优

## 研究立场与版本边界

本工程属于**真实数据的探索性算法改进实现**，不是作者原始FVIM公开源码逐位复刻，也不能直接宣称已提升俯仰/偏航角精度。引用论文《FVIM-MVMD结合样本熵的MEMS陀螺仪去噪方法研究》（陆金波等，2026）提供的 FVIM 四向量更新式(7)–(11)，沿用 v0.2 已有的 `gyro_fvim.m` 工程复现思想，并在本工程中实现四优胜者引导搜索。原文未完整规定全部求解细节、初始化、处理边界，因此这里的 FVIM 标记为**FVIM-style 可复现工程版**。

当前研究路线：双通道联合 MVMD → CS+SampEn 改进联合模态重构 → K/α 物理保真适应度联合优化 → 独立滚转频率验证 → 有符号角速度/姿态解算 RMSE。固定标定值按工况查表，不能拿验证真值反向调偏置、灵敏度或滤波参数。

### 与已完成 E07-C 的联系

E07-C 已在真实 Z3-1 中发现：参数仅相差约 13 的 α=292.9731 / 306.1287，使 IMF2 的 SampEn 从1.79318跨越阈值1.8到1.81506，原算法从混叠小波处理跳至完全丢弃，额外降噪代理差异 a约3.18 dB、s约2.92 dB；固定分类后 α 的影响不超过约0.5 dB。本实验应对的是**重构策略对硬阈值过敏**，不是单纯提高 SNR 代理数字。

## 运行方法

1. 解压后，在 MATLAB 当前目录切换至本工程根目录。
2. 直接运行 `E07D_run`。默认附带真实 `Z3-1_E06B_record.mat`，只读取此训练数据；不会读取在 E06-A/B 开发中看过的 Z3-2。
3. `E07D_config.m` 中可填写 `cfg.dataRoot='E:\\...\\20200824';`，从而在训练结束且参数锁定后，检查历史原始 TXT 中**其他频率**的 `Z6-2.TXT`、`W6-20.TXT`。首次无数据根目录时留空，输出训练结果后停止。
4. 如果实际 TXT 没有 Z6-2 / W6-20，程序跳过并报告，不生成伪验证结果。

注意：当前MATLAB环境必须支持 `readmatrix`、`table`、`writetable`、`string`、`fft` 等函数。分解使用内置 MATLAB，无Signal/Wavelet工具箱依赖。此工程已静态检查，并未由助手在 MATLAB 本体执行。

## 当前创新实现（可以审查和消融）

`E07D_soft_weights.m`：基于两路联合 CS/SampEn，定义连续共享的 keep/mix 权重；双路同一IMF使用同一权重，在原本硬切换的位置由连续函数平滑过渡。默认宽度 cs=0.045、SampEn=0.085，混叠门控指数2。参数当前仅有设计依据，没有独立数据支持其最优性。`E07D_soft_reconstruct.m`：每个模式以 `keep*IMF + mix*Haar(IMF)` 重构，DC 原样保留。尚未添加新的动态相位自估计器。

`E07D_score.m`：新训练适应度为两路非目标残差代理、动态边带幅值、相位变化、双通道相对相位（固定归一化权重0.55/0.25/0.12/0.08），并对超出边带99%～101%及0.2°相位窗的参数增加固定平方惩罚；原对照 `E07D_entropy.m` 为最小包络熵工程代理。对比同一训练集，使用相同求解器与收敛筛选。**原对照的重构使用原工程硬CS/SampEn+WT**。

`E07D_run.m`：两个优化器使用相同四个初始点，各8个新候选，采用四优胜者引导更新，公共MVMD缓存不重复分解，至多20次不同参数分解。所有计算候选双目标均记录。训练最终分别按各自算法的种群选优；另外给出同一总候选池事后两目标排名，仅作为公平性诊断，不冒充各自算法曾事先使用其他分支候选。**不能把小预算搜索称为已找到全局最优解。**

## 结果目录 `results_E07D`

- `E07D_solvers.csv`：每一实际分解，参数/收敛/重构残差/耗时；逐个增量落盘。
- `E07D_search_trace.csv`：熵目标与联合目标各自每轮最优及累计唯一求解次数。
- `E07D_locked_params.csv`：本轮各目标锁定的 K、α。
- `E07D_shared_pool_diagnostic.csv`：全体已计算候选两个适应度的事后共同池最佳（诊断用途）。
- `E07D_train_ablation.csv`：同一训练 Z3-1，旧/新参数 × 硬/软重构四格消融。
- `E07D_old_IMF.csv`、`E07D_new_IMF.csv`：原分类及新连续权重。
- `E07D_train_spectrum.png`、`E07D_train_outputs.mat`：训练信号及示意。
- `E07D_decision.txt`：训练是否有初步改善，禁止当作独立验证。
- `E07D_holdout_comparison.csv`、`E07D_holdout_solver.csv`：仅数据目录存在且找到预设外部工况时生成；独立滚转频率，非无条件新盲测。

## 研究的三个解释限制

1. 噪声指标是单频/多频拟合的**非目标残差代理**，既非真正无噪声真值 SNR，也不能因此断言丢掉的所有非目标分量都是噪声。
2. 真实跨工况角度对照尚需三框运动学坐标关系，E07-D 本身不输出真正 Ωx、Ωy、俯仰偏航RMSE。
3. E07-C 中“直接丢 IMF2”在训练数据看起来更干净，不能当成所有频率都应丢 IMF2 的规律；新权重目的在于连续、稳定且具有可泛化性。

## 后续必要动作

先执行 `E07D_run`，上传 `E07D_solvers.csv`、`E07D_search_trace.csv`、`E07D_train_ablation.csv`、`E07D_decision.txt`、`E07D_new_IMF.csv`。基于四格消融定量拆分寻优与重构贡献；只有有据可循时增加 FVIM 搜索预算。用未参与选择的不同频率数据做最终对照，再进入真实有符号速率和姿态 RMSE，不需要重启零偏在线估计或滚转相位跟踪课题。
