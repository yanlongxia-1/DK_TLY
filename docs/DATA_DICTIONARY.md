## 主要参数

| 参数 | 当前冻结值/范围 | 含义与边界 |
|---|---:|---|
| `fs` | 1000 Hz | 历史名义采样率，需独立核实时间戳 |
| `K` | 基线 8；搜索 4～8 或工程全域 2～10 | MVMD 模态数 |
| `alpha` | 基线 154.157959862 | MVMD 带宽惩罚 |
| `tau` | 0 | noise-tolerant MVMD；非零 AC 残差不自动代表错误 |
| `tol` | `1e-5` | 同时检查模态谱变化与中心频率变化 |
| `csKeep/sampKeep` | 0.22 / 1.5 | 工程化“保留”阈值，不是论文唯一真值 |
| `csMixed/sampMixed` | 0.08 / 1.8 | 工程化“混叠小波”阈值；E07-C 已发现 1.8 附近跳变 |
| Haar | 4 层、阈值倍率 0.6 | 基线重构；E06-B 另用共享 6 层、倍率 0.75 |
| 训练/验证 | 10%～50% / 60%～95% | 同一记录内的时间分割，不等价于全新盲测 |
