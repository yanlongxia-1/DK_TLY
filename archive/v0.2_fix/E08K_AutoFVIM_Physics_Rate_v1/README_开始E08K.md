# E08-K：改进物理保真目标下的自动 K、α 寻优与9 Hz角速度对照

> **当前状态：已制作与静态检查，尚未在 MATLAB 真实 TXT 上运行。** 本工程是“4个领导候选引导”的 FVIM-style 工程搜索，**不是原论文作者 FVIM 的精确源码复现**。实验主线：FVIM-MVMD 改进优先；固定参数保底。

## 1. 本轮解决什么问题

E08-J 在两组9 Hz训练数据上共24次求解都严格收敛。Z9-1的12组硬重构旧保真规则全部拒绝，新物理规则全部接纳。E08-J 固定候选最高探索得分是 K=5、α≈154.158，但**不是自动 FVIM 的成果**。现在把评价规则冻结并接入 FVIM-style 自动搜索，同时使用真实 W9-60 等效有符号外框角速度 RMSE 作开发阶段验证。

## 2. 输入和绝对隔离

- 训练：`W9-10.TXT`、`Z9-1.TXT`，TXT 第4列 a、第7列 s；**寻优仅可读取这两个文件的双通道信号和已知9 Hz**，不得读取任何编码器真值。
- 开发期锁定检查：`W9-60.TXT`、`Z9-3.TXT`；这两个文件已在 E08-E～E08-I 看过，**不是盲测**。不要在它们上面修改参数或阈值。
- W9-60等效外框角速度RMSE：统一调用 `calibration_final.csv` 中9 Hz固定标定、E9零输入谐波与转台外/内框角度。不是完整机体 Ωx/Ωy 或姿态角 RMSE。
- 训练/检查窗口：相同固定 0.5 s 起始跳过、95%末尾截止、最多最后3 s；窗口算法在代码中冻结。

## 3. 方法和预算

| 方法 | K、α来源 | 重构 |
|---|---|---|
| raw | 无滤波 | — |
| fixed_baseline | K8 / α154.157959862，原强基准 | 原硬重构 |
| developer_K5 | K5 / α154.157959862，E08-J 固定候选 | 原硬重构 |
| entropy_auto | 最小包络熵工程代理，**从所有共同候选中选** | 原硬重构 |
| physics_auto | 新双通道物理保真＋噪声代理目标，**从所有共同候选中选** | 原硬重构 |

共同初始4候选：K8/154、K5/154、K7/450、K8/320；两目标各最多4次引导提案，总共至多12组不同参数。每组在W9-10/Z9-1各运行1次MVMD，共至多24次训练求解（另有4种方法在2份开发数据上按不同K/α复用解，最多8次）。同一候选计算两种适应度，共享缓存，最后**每个目标从同一候选合集选最优**，纠正早期“各用自己的候选池”问题。搜索预算、随机种子、最大2400迭代、严格收敛1e-5、AC误差≤15%锁定。注意研究上的比较公平性与正式作者 FVIM 搜索逻辑复现是两件事。

**物理判据**：相对本通道目标频点最大原始幅值≥10%的强分量保留99～101%和0.2°相位，强/强两路相对相位0.2°；弱分量的复系数变化量不得超过该通道最大目标幅值的1%。上述阈值来自已见开发数据，仅用于此阶段核查；最终仍需全新测试集。

**目标区分**：物理目标在训练阶段要求两路非目标残差代理均非负改善；最弱通道为主、双路均值为辅，并对K作极小复杂度惩罚。旧熵目标仍按最小包络熵打分。两者都不使用转台角速度真值。**非目标残差不是有干净真值的真实SNR**。

## 4. MATLAB运行（只需改1处路径）

1. 解压ZIP，使用MATLAB打开 `E08K_config.m`，修改 `cfg.dataRoot` 为完整的20200824 TXT文件总目录；不要修改其他字段。
2. 将MATLAB当前文件夹切到 `E08K_AutoFVIM_Physics_Rate_v1`。
3. 依次运行：

```matlab
E08K_selftest
E08K_run
E08K_analyze
```

4. 输出全部写入 `results_E08K_9Hz`，训练过程中逐候选写入CSV，可用以排查中断：

| 输出 | 含义 |
|---|---|
| `E08K_train_candidates.csv` | 所有共同候选旧/新适应度与可行性 |
| `E08K_train_solver.csv` | 两训练文件严格收敛、迭代与AC误差 |
| `E08K_search_trace.csv` | 两分支搜索过程，注意轨迹与最终共同池选择不同 |
| `E08K_locked_params.csv` | **冻结的旧/新自动参数及两种固定基准** |
| `E08K_test_solver.csv` | 检查工况是否得到有效解 |
| `E08K_test_metrics.csv` | 降噪代理、强分量幅相、W类真实等效角速度RMSE |
| `E08K_series_W9_60_TXT.csv` | W9-60角速度时序曲线数据（若能完成） |
| `E08K_comparison.txt` | 有效方法与原始数据的角速度误差对照 |
| `E08K_decision.txt` | 自动选参及锁定检查的整体记录 |

没有收敛的解不得使用其重构快照计算正式RMSE；计算失败明确记录，不把NaN当Inf伪造胜出。

## 5. 本轮结束条件、后续E09

不管自动方案是否优于强基准，都报告失败率及在相同工况两种方法同时有效时的成对RMSE。若 K5 固定强于自动寻优，这是算法结果，不允许用测试集再挑参数。**这轮不重开一系列无限的小优化**。E08-K 结果确立后，下一阶段优先 E09-A 姿态运动学框架及首次角度RMSE；若原始三框角度和安装矩阵不足以区分俯仰/偏航真值，则先独立解决真值构建问题，不能把转台单框角误称偏航或俯仰。
