# E07-A 有物理约束的联合评价目标预检（不是FVIM优化器）

## 任务与运行
目标：在E06-B共享阈值收缩失败后，限定计算预算，初步检查调整双通道联合MVMD的带宽alpha，能否在不破坏动态边带的前提下增加残差抑制；为后续设计受约束FVIM目标函数提供证据。

- 输入材料：E06-B前一轮留下的 `Z3-1_E06B_record.mat`、`Z3-2_E06B_record.mat`，已经放在 `inputs` 下。它们包含原始X、冻结基线baseline和时间t。
- 训练：Z3-1（2/4Hz边带）；固定K=8，仅额外测试alpha=80和300两组。alpha=154.157959862使用已经保存的旧基线，不重跑。
- 判据（仅训练）：双路各自额外残差抑制 >=1dB，同时两路有效边带幅值保持率99%-101%、边带相位变化<=0.2度。使用多频正余弦最小二乘拟合的非目标残差，仅是噪声代理，不代表真值SNR。阈值提前固定，不能调整。
- 只有训练合格，才在完全未用于选择alpha的Z3-2 (1/5Hz)上做一次确认。若训练不合格，直接停止，不重新测试或调整Z3-2。
- 最高仅运行3次新的联合MVMD分解（两次训练、一次保留测试）；K和重构策略不变，不做大量FVIM网格。

运行：解压后将MATLAB当前目录切换到工程根目录，执行：

```matlab
E07A_run
```

输出：`results_E07A/E07A_train_objective.csv`、`E07A_solver.csv`、`E07A_decision.txt`；仅训练出现合格候选时，额外输出 `E07A_heldout_objective.csv`。

## 研究边界
1. 这是“受约束评价目标是否有价值”的小预算预检，**没有运行 FVIM 算法，也没有实现创新方法**；不得写成“改进FVIM-MVMD已成功”。
2. Z3-2此前已用于E06A和E06B，因此它只是在“本轮alpha选择未使用”的意义上留出，不是整个项目的全新盲测数据。最终论文需锁定方法后，另选未参与调参的工况。
3. 非目标残差也可能包含真实动态信息，因此降噪代理不是独立无噪声信号真值。
4. 训练若失败，直接终止这个“只调整alpha”的方向，不反复尝试K/alpha组合；转向新的物理一致性/耦合约束模型，在新实验里证明实际改进。
5. 本程序仅作算法预检，尚未经MATLAB实机验证。请按具体报错回传。
