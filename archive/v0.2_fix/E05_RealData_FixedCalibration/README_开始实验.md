# E05｜真实双正交 MEMS 陀螺：固定标定参数、统一滤波与解调对照

## 研究边界（必须遵守）

- **真实 TXT 第1/2/3列是转台外/中/内框角度（deg），不是角速度。**
- 第4列 a、第7列 s。采样率按 1000 Hz 假设；已知各工况的滚转频率。
- **每个工况的零偏 `[ba,bs]` 和标度因数 `[Ka,Ks]` 必须是提前实测的固定数值。** 不得从验证区间按 RMSE 反向估计。
- 后续确实要进行有符号 Ωx/Ωy 解调与姿态角解算；暂不研究在线零偏、标度因数、滚转角估计。
- 当前双路物理模型：`s=Ks*(OmegaX*cos(phi)+OmegaY*sin(phi))+bs`，`a=Ka*(OmegaX*sin(phi)-OmegaY*cos(phi))+ba`。
- 本包 E05 为**原始、固定参数振荡 KF、冻结参数论文风格 MVMD 的统一基准**；**不是已经有效的“改进 FVIM-MVMD”**。先前 E03 物理保护触发数为零，不可宣称具有增益。

## 使用方法（只需一遍准备）

1. 解压整个文件夹到 MATLAB 工作目录；将 `W3-10.txt` 和 `W3-20.txt` 复制到 `data/`。也可在 `E05_config.m` 修改文件路径。
2. 在 `E05_config.m` 填写**真实的每工况** `bias=[ba,bs]` 和 `scale=[Ka,Ks]`，以及滚转频率、方向和固定初相位。**默认 NaN 表示缺失，不是数值0。** 曾讨论的偏置示例 [-0.186041,-0.072559] 不会被程序自动拿来使用。
3. MATLAB 当前文件夹切到工程根目录，运行 `E05_run_real`。
4. 程序逐文件处理；找不到文件会跳过；不执行 FVIM 参数寻优。每个文件执行 1 次 MVMD、1 次固定 KF。

## 自动输出

`results/W3-10/` 和 `results/W3-20/` 下：

- `E05_signal_metrics.csv`：两路幅值保持、相位变化、相对相位、单频 SNR **代理**、RMSE（相对原始测量，非真值）
- `E05_solver_summary.csv`：固定 K,α、MVMD 收敛、交流重构残差、耗时
- `E05_modes.csv`：CS/SampEn、模态分类；未收敛时不生成可靠模态表
- `E05_filtered_comparison.png`：三方法双路波形
- `E05_gimbal_angles_position.csv`：真实转台**角位置**及展开角度（不把它们称为横向角速度）
- `E05_data.mat`：后续对照实验可直接复用，避免再次重复 MVMD
- 若标定值完整：`E05_signed_transverse_rates.csv`、`E05_signed_rates.png`：相同滚转相位假设下的有符号横向角速度
- 若标定值缺失：`E05_REQUIRED_CALIBRATION.txt`：仅输出传感器信号层结果；不会制造 deg/s 值
- `E05_attitude_status.txt`：说明为何暂不报告实际姿态角 RMSE

## 关于姿态角（不是取消角度解算）

即便有了 Ωx、Ωy 和每个工况已知滚转频率，也不能把外、中、内框角度直接当作横向角速度或不经坐标变换当成俯仰/偏航真值。必须确认转台外/中/内旋转轴、方向、组合顺序、零位、传感器安装以及 Ωx/Ωy 表达坐标系。

已附 `E05_reference_attitude.m` **受控参考对照模块**，在 `cfg.reference.enabled=false` 时自动跳过。只有上述物理定义独立核实后，才配置该模块并启用。它首先提供 SO(3) 姿态角距离误差，不会凭空冒充俯仰、偏航 RMSE；等物理坐标约定确认后再增加对应欧拉角指标。

## 如何公平比较

- 使用相同 `[60%,95%]` 区间、同一滚转频率、同一固定标定、同一解调公式。
- KF 使用固定 `Qosc/R=1e-6`、`Qbias/R=1e-8`；`R` 仅从训练区间谐波残差估计，KF 在全记录上递推；不同于用户历史旧 KF 的每工况分别寻优版本。
- MVMD 冻结使用 W3-10 已取得的 `K=8, α=154.1579598620, τ=0`，对 W3-20 **不重新优化**；结果非收敛时不提供该算法的有效对照。
- 论文原作者完整代码并未提供；现有分类阈值是工程复现，严禁称为逐行还原原作者实现。
- W3-10 的验证片段此前已被看过，仅是回顾对照；W3-20 冻结参数的跨工况评价比反复挑选 W3-10 结果更有价值。
- 真实数据没有可靠的无噪声真值时，单频 SNR 增益只是**代理指标**，不能证明真实角速度或姿态 RMSE 降低。

## 资源保护与程序风险

- 本实验绝不会运行此前导致电脑卡死的大型 FVIM 网格/多种子寻优；每工况最多执行一次 MVMD（1200次内部迭代上限），仍为离线 MATLAB 算法。
- 建议运行时关注任务管理器；遇到内存、磁盘异常应停止。
- 现有设备没有 MATLAB 环境可实机验证脚本，已做人工检查与结构一致性检查；如 MATLAB 报错，原样反馈。
- 本包的任务是建立**可重用的数据对照基线**，随后再进行真正改变滤波结果的改进方案与独立样本验证。
