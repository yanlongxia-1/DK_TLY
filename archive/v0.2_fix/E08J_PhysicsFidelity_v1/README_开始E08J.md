# E08-J｜双通道物理保真评价修正与小 K 候选检验（2026-10-27）

## 本阶段研究问题

E08-I 的真实 Z9-1 结果显示：有效动态边带为 8 / 10 Hz；9 Hz 分量在 a 通道约 0.001306，相比 8/10 Hz 主边带约低 25～29 倍。硬重构 K=3 α=154.157959862 的 a 路 9 Hz 幅值保持 103.074%，相应的绝对改变量却只有约 4.0e-5。其余主要边带的原有 99–101% 幅值与 0.2° 相位要求满足。另有 E08-I 的 W9-60 开发诊断显示，α154.158 的 K=3/4/5 严格收敛，但 K=6/7 未收敛。这意味着 E08-H 的 `NO_TRAINING_FEASIBLE` 不能直接解释为求解器普遍无效。

**本次不更改 MVMD 分解公式、IMF CS/SampEn 硬分类、小波处理或任何求解器容差，也不执行 FVIM 自动寻优。** 唯一改动：把对弱幅值目标频点不稳定的百分比要求，改为与本通道最大物理目标幅值同量纲的绝对复系数误差限，同时继续对强目标保持原严格幅相约束。

## 两套预先固定的指标

**原指标（对照）：** 全部目标频率的两路幅值保持 99%～101%；原有显著相位小于等于 0.2°；所有目标频率的双路相对相位变化小于等于 0.2°。

**改进指标（开发版）：** 对每路，先从原始双通道数据（不读取滤波输出/编码器参考）估计目标频率复谐波系数 `C_raw,ch(f)`；取同通道目标频率中的最大原始幅值 `Aref,ch=max_f|C_raw,ch(f)|`。对每一个通道×频点：

- 强分量：`|C_raw| >= 0.10*Aref`，幅值偏差仍不超过 1%，单通道相位变化仍不超过 0.2°。
- 弱分量：`|C_filtered-C_raw| <= 0.01*Aref`，其物理含义是**有绝对尺度约束的复系数偏差**，不是放弃保护弱分量；不要求不稳定的弱分量相位角满足 0.2°。
- 双通道物理相位：**当该频点双路均是强分量**，两路相对相位变化不超过 0.2°；其余情形由两通道各自复系数误差限制保护。
- 对非目标频率的残差削减仍以单/多谐波拟合后的 RMS 变化的 dB 代理表示，不能叫真实 SNR。

阈值 `0.10` 和 `0.01` 是看到 Z9-1 后设计的**开发阶段规则**。它们不能因为回顾性 E08-I 检查通过就称作独立验证，更不能为了得到理想结果使用测试文件重新修改。

## 软件文件

- `E08J_config.m`：固定物理阈值、候选网格、训练文件、计算预算，保存原始配置。
- `E08J_physics_metrics.m`：对双通道原始/重构信号进行同频点谐波最小二乘，输出逐频点复系数偏差和旧/新保真判据。
- `E08J_selftest.m`：合成信号快速回归检查：弱成分的相对偏差、强成分幅值/相位损坏、MVMD 调用链。此自检**不是**真值精度验证。
- `E08J_run.m`：原版 MVMD + 原 CS/SampEn 重构，所有网格候选公平求解；同一次分解派生 `hard_paper` 和 `all_modes`；训练仅 W9-10、Z9-1。
- `reference_E08I/`：用户 E08-I 的真实 CSV 和 Python 回顾性审计脚本。审计不需要新的 MATLAB 分解，不能视为新实验结果。
- 其余 `gyro_*.m`、`read_gyro_txt.m`、`E08G_mvmd_damped.m` 保留已验证旧工程依赖。

## 如何运行

1. 解压到新的目录，不覆盖 E08-I 及之前的结果。MATLAB 将当前目录设为该目录，确认与 E08-I 相同的原始 TXT 数据存在。
2. 修改 `E08J_config.m` 中 `cfg.dataRoot` 为历史 TXT 根目录（会查找子目录）。不要在此阶段修改任意研究阈值。
3. 执行：

```matlab
E08J_selftest
E08J_run
```

4. 运行结果位于 `results_E08J/`。只评价严格收敛并满足 AC 重构误差不超过 15% 的候选；没有通过的结果留空，而不是填 0 或认为 RMSE 无穷大。

## 结果文件、判定、停止条件

| 文件 | 含义 |
| --- | --- |
| `E08J_cases.csv` | 每文件、K、α、硬/全模态重构的旧新幅相判定，求解器严格收敛，残差代理 |
| `E08J_band_detail.csv` | 每个通道×目标频率的强/弱标签、保持率、绝对复系数偏差和是否通过 |
| `E08J_modes.csv` | IMF 中心频率、能量、CS、SampEn 与硬分类 |
| `E08J_train_selection.csv` | 仅根据 W9-10 和 Z9-1 两份训练文件推导的可行候选与探索性排序（**不是 FVIM 寻优**） |
| `E08J_decision.txt` | 当前结论、已知局限、合法的后续任务 |
| `E08J_issues.csv` | 异常记录，有错误时生成 |
| `E08J_frozen_config.mat` | 保存所有试验参数，利于 Git 版本归档 |

本轮 12 组 (K, α) × 2 个训练文件，**最多 24 次 MVMD 求解**，所有求解器阈值沿用 E08-H (`maxIter=2400`, `tol=1e-5`, 中心频率阈值源自原求解器，三次稳定，`eta=1`, `tau=0`)。中间写 CSV；出现失败记录并继续，不对测试真值反向调参。

原已看开发数据 W9-60、Z9-3 被默认禁用 (`cfg.enableKnownDevelopment=false`)；如需机制复核可启用，但**不能用于选择 K、α**。请不要将两者重新称为独立盲测。

### E08-J 完成条件

- 强边带继续满足原99–101%和0.2°，双通道强频点相对相位符合限制。
- 弱频点复系数误差在有物理量纲的界限内，且原/新判据差异透明记录。
- 训练 W9-10、Z9-1 至少出现一个两份都严格可行的候选；若没有，保留负面结果，并使用逐频点 CSV 判断源头。
- 以上条件通过后，立即进入 **E08-K：真正的 FVIM（须核验原算法方程）+ 改进目标、同预算候选与固定强基准对照 → 独立真实角速度 RMSE**。E08-J 只能证明判据和候选可行性，不能宣称FVIM精度创新完成。

**重要：** 原始数据前三列是转台的实际角度，4/7列为双路陀螺输出；E08-J 未输出编码器角速度或最终俯仰/偏航角度 RMSE。固定零偏与等效复标度表在 E08-K/E09 正式使用，禁止借评价窗口或真值重新标定。
