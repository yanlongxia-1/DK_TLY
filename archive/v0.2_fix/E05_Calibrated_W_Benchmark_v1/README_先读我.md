# E05 标定模型接入与真实 W 工况滤波对照（保守验证版）

## 使用目的
基于已经完成的 229 文件标定结果，使用**未参与该标定回归的 W20/W60 数据**，在统一的标定前提下比较：未滤波、冻结参数振荡 KF、冻结参数 MVMD。不会再运行 FVIM 寻优。

此版本首先检验**有符号外框恒速输入的等效恢复精度**，不将它冒充一般运动情况下的 body Ωx/Ωy，更不输出未经确认坐标系的姿态角 RMSE。完成此关后才进入多轴解调与姿态积分。

## 运行

1. 解压文件夹，在 MATLAB 打开工程根目录。
2. 修改 `E05_calibrated_config.m` 的 `cfg.dataRoot` 为你 20200824 原始数据文件夹（可含多层子目录），里面必须同时有 `E3.TXT` 和 `W3-20.TXT`。
3. `calibration_final.csv` 已放在工程根目录，无需重新运行 229 文件标定。
4. 执行 `E05_run_calibrated`。
5. 将 `results_E05_calibrated/W3-20` 文件夹里的 `E05_solver.csv`、`E05_signal_metrics.csv`、`E05_outer_rate_metrics.csv` 及两张 PNG 发给 ChatGPT 分析。
6. 首组正常后，将 `cfg.testFiles` 改为 `{'W3-60.TXT','W5-20.TXT','W5-60.TXT'}`，逐组运行；别一开始同时跑几十组。

## 标定与模型含义（重要）
标定源码以 E 同频率纯滚转响应为零输入基线：

`y_a = b_E,a + (C_E,a cos(theta) + S_E,a sin(theta)) + Ω_outer * (kAcos cos(theta) + kAsin sin(theta)) + noise`

`s` 通道同理。因此需要减掉 *E 的固定谐波零输入响应*，不能只减直流。这里的复数 `H=C+iS` **只是系数的记账方式**。如果想用复指数运算，正确的是 `real(conj(H)*exp(1i*theta))`；不能用 `real(H*exp(1i*theta))`。

本程序提取 Ωouter 的公式是双路加权投影：

`Ωhat=(Ga*(a-bEa-hEa)+Gs*(s-bEs-hEs))/(Ga^2+Gs^2)`。

这里 Ωouter 是**有符号外框恒速输入的等效估计**。标度因数是在特定转台几何/运动输入下得到的复响应，尚不能作为完整三维的绝对 Ka/Ks 使用。尚缺完整转台三框旋转轴、正方向、零位和陀螺安装矩阵，不能直接声称已求得任意 body Ωx/Ωy 或真实俯仰偏航角。

## 两种相位
- encoder：直接使用测试文件第3列内框实测角度，属于离线参考（适合审核标定和滤波影响）。
- fixed：使用已知 fRoll 并以文件初始内框角为相位原点，属于台架已知初相位的条件性固定频率模型。**不是在线滚转角估计**。
两种相位均不用于重新拟合标定或调节滤波参数，只用于输出对照。

## 注意事项
- `W3-20` 是标定意义上的 W 留出文件，但以前已多次用于滤波实验诊断，不能称为新鲜滤波盲测；最终评判新改进需要另选未参与算法开发的数据工况。
- 实验结果既有原始/KF/MVMD 单频 SNR **代理值**，又有外框角速度真实标记。代理增益不等于真实 SNR。
- 若求解器未收敛，仍输出 raw/KF，但**不输出 MVMD 数值对照**。
- 一个文件只做一次 MVMD，不会重复运行大规模 FVIM，且逐文件保存。
- 本代码在当前环境完成静态检查、合成代数一致性检查，但无法执行 MATLAB 实机；实际报错请返回原始错误信息。
