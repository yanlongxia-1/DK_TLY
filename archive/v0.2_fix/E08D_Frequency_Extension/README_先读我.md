# E08-C｜已知滚转频率条件化的双通道 FVIM-MVMD 可行性实验

## 目的与边界
本实验优先验证用户提出的**跨滚转频率参数自适应**，必要时再退回3Hz单频率。并不对零偏、标度因数、滚转频率本身做在线估计。

首次对照**默认0–500 Hz均匀中心频率初始化** vs **以已知滚转频率引导的初始化**，不改变MVMD的更新方程、停止阈值或迭代上限。训练阶段使用 W3-10、Z3-1 和 W9-10、Z9-1；每频率优化同一组 K/alpha，使恒速和动态输入共用参数。采用原有E07-D联合幅相保真适应度、硬重构，最大8组候选/频率、最多16次训练MVMD分解/频率，避免大规模搜索。FVIM更新仅为可复核的**四领先者FVIM风格工程复现**，不是原作者源码的严格复刻。

## 运行
1. 解压后，编辑 `E08C_config.m` 中 `cfg.dataRoot` 为完整的 `20200824` TXT 数据根目录（支持子文件夹递归读取）。
2. MATLAB工作目录切到工程根目录，运行 `E08C_selftest`，接着运行 `E08C_run`。
3. 输出在 `results_E08C`：`E08C_init_diagnostic.csv`、`E08C_solver.csv`、`E08C_train_search.csv`、`E08C_locked_params.csv`、`E08C_holdout_metrics.csv`、`E08C_decision.txt`。
4. 首轮两个频率合计：初始化诊断4次联合分解，训练搜索不超过32次联合分解，锁定检查按是否选择新参数再做少量分解。所有MATLAB输出保留具体收敛、迭代、delta、centerDeltaHz、AC重构误差，不放宽质量门槛。

## 不泄漏、不误判
- 训练时**只读取** Wf-10、Zf-1；Wf-20、Zf-2在选中K/alpha后才读取。
- 已在历史研究中查看过的W3-20、W9-20、Z3-2等不能称作新的盲测。
- 适应度只有原始测量的单/多谐波残差、幅相保真代理；没有无噪声真值SNR，也没有机体Omega_x/Omega_y或真实姿态RMSE。
- 如果不收敛，不能仅凭低AC重构误差认定解有效；必须同时核查`delta`和`centerDeltaHz`及迭代次数。
- **参数频率条件化**不等于真正在线无工况输入自适应；已知滚转频率属于当前模型前提。

## 结果判断和后续
- 支持继续：3Hz与9Hz都有在W/Z训练上收敛且满足保真的锁定K/alpha，锁定后恒速/动态工况能稳定分解；比较所选参数与在相同初始化下的冻结K8/alpha154对照，确认频率条件化是否有真实增益。
- 尚不支持推广：只有单个频率成立、或训练成立但跨速度/动态工况不能重现，此时先检查求解稳定性，不能直接宣布跨频率成功。
- 逐项解决可修复的数值问题后，如果依然无法建立可靠多频率方法，才按预定兜底转3Hz单工况，集中精度优化。

## 关键对照
E08A原`E08A_config.m`默认`cfg.mvmd.maxIterations=1200`。用户新传的W9-20 CSV仍记录1200次，不足以证明更改到2400后的效果。此工程明确打印配置并导出每次求解终止数据。
