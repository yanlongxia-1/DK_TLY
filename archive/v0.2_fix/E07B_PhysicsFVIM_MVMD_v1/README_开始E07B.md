# E07-B｜双通道物理保真 FVIM-style 目标函数实验 v1.0

## 直接运行

1. 解压全部文件，不要覆盖 E05、E06A/B、E07A 工程。
2. MATLAB `Current Folder` 切到本工程文件夹。
3. 直接运行：

```matlab
E07B_run
```

`inputs/` 已自带你前面上传的 Z3-1、Z3-2 E06B 数据（原始 X、时间 t、冻结 MVMD baseline）。**当前不需要重复导入全部229个 TXT**，也不需要重新运行 E06A、E06B 或 E07A。

运行 E07B 前会自动执行 `E07B_selftest()`（纯合成公式自检、不跑MVMD）。本工程**没有 MATLAB 实机执行验证**，如有具体报错请回传文件和报错堆栈。

## 本实验究竟在改什么？

原有工程实现的是“论文流程的**工程代理复现**”：双通道联合 MVMD + CS/SampEn 双路配对筛选 + 部分 IMF 单通道 Haar 小波。**原作者的完整 FVIM 源代码、某些适应度细节和小波配置未知**，不能声称逐行复现。

本次只改变群体搜索时的**适应度函数**，保持 MVMD 求解器、两路联合输入方式、IMF分类阈值、小波方案完全相同：

- **旧代理目标**：对各路每个 IMF 计算归一化包络熵，每路取最小后求均值，加空模态惩罚；越小越好。这是之前工程中的原论文方法代理基线，而不是作者已公开的准确可执行适应度。
- **新联合目标**：同时惩罚双路非目标频率残差功率、强动态边带的幅值变化、单路有效边带相位变化、双路相对相位变化；权重固定，越小越好。只把 **Z3-1** 的2/4Hz边带及3Hz载波作为训练目标谱线，不使用外框运动角度作为优化输入。
- 同一候选同时计算旧/新分数，各自独立选择自己的最优候选；不允许拿“比较函数”偷偷调整物理模型。
- 候选参数是 K 与 alpha（2维），同时保持常用的双通道共享中心频率 MVMD 分解；这种共享分解**不是我们的创新**。

注意：共享频率和双通道幅相物理关系存在不确定性，不能把所有频率强制设为90°。本次目标只约束已可辨的动态边带前后**相位变化**，而不是强行设双路相位=90°。

## 有预算上限的四优胜者FVIM-style有限演化

**本工程实现了两条四优胜者引导的 FVIM-style 候选更新轨迹，但它并不是原论文 FVIM 的严格同构实现，也不能据此声称算法已充分收敛或达到全局最优。**

- 共享四个初始化：`(K,alpha)=(8,154.157959862),(6,110),(6,300),(4,220)`；两目标同一起跑点。
- 旧熵目标和新物理目标各自新增4轮四优胜者引导候选。
- 同一 K/alpha 的 MVMD 结果只解算一次（缓存），训练最多 **12 次不同MVMD联合分解**，所有分解都限制为最多1200次迭代。
- 不收敛，或 AC 重构残差超过15%的参数直接判无效，不用失败解参与排名。
- `Z3-2` 已在更早的 E06A、E06B 中看过：因此只算**参数冻结后的交叉场景检查**，不是全项目全新的独立盲测。
- 若新目标在Z3-1没满足下述事先规则，则**不运行Z3-2，不追加 K/alpha 网格，不更改权重**。
- 若训练通过，才在Z3-2为两个冻结选定参数最多各新增1次MVMD分解（同参数缓存）。

## 预先冻结的验收条件

训练 Z3-1：

1. 2、4Hz边带相对于**原始测量**的幅值保持为99%～101%；已满足幅值可辨阈值的相位变化≤0.2°；
2. 相对于之前冻结 MVMD 的非目标残差**代理**，a与s两路各额外改善至少1dB；
3. 与旧熵类目标选出的候选相比，至少在两路均有可见的0.3dB额外净改善，**或**旧候选不满足边带约束；
4. 没有任何参数在“没收敛”的状态下被采纳。

未通过即 `STOP`，不调整。通过后，在Z3-2使用1/5Hz边带核验同一门槛。保真指标是与带噪原始波形的谐波拟合对比，SNR是单频/非目标代理，**不是干净真值SNR；不保证最终角速度RMSE或姿态角RMSE改善。**

## 输出文件

位置：`results_E07B/`

| 文件 | 内容 |
|---|---|
| `E07B_solver.csv` | 每一次实际MVMD求解的K、alpha、收敛状态、耗时和重构残差 |
| `E07B_train_candidates.csv` | 两条目标的候选、缓存与评分（包含失败候选） |
| `E07B_search_trace.csv` | 每代两个目标的最佳参数/fitness轨迹 |
| `E07B_train_comparison.csv` | 冻结MVMD、旧熵优化、新联合目标三者同一训练数据对照 |
| `E07B_train_outputs.mat` | 三种训练输出时序，供后续复算 |
| `E07B_train_spectrum.png` | 训练频谱对比图（若可用MATLAB图形系统） |
| `E07B_entropy_IMF_modes.csv` / `E07B_joint_IMF_modes.csv` | 两目标最佳方案各IMF分类细节 |
| `E07B_decision.txt` | 是否满足预先冻结的停止规则 |
| `E07B_locked_check.csv` | **仅训练通过**时生成，Z3-2 交叉场景检查 |

如果希望完全复现，不要手动调整`E07B_config.m`的权重、阈值和随机种子；只在有显式方法学理由时建立新版本及新数据集。

## 与论文的关系与严谨边界

- **真实实验目前已知**：E05 W3-20 MVMD保持幅相较好，但在等效外框输入逐点RMSE方面不如KF；E06A Z3-1/Z3-2边带均保留约99%+；E06B共享Haar阈值失败；E07A两个alpha试探未达标。这些结果真实、保留。
- **此次真正新增**：FVIM-style优化的适应度设计：双通道非目标残差+有效动态边带幅相+两路相对相位保真，采用缓存和有限预算公平优化对照。
- **尚未证实**：新目标会在训练/交叉场景真正改善；进一步横向角速度、俯仰角/偏航角RMSE；部署实时性能。
- **科学公平**：不因为KF某一指标优于MVMD就说MVMD更好；论文可聚焦同类MVMD与其消融，但比较对象范围要事先说明。
- **下一步**：若E07B成功，再锁定方案在**未参与方法决策的新W/Z频率工况**验证，复用已完成的固定频率标定，最后做有符号Ωx/Ωy与姿态解算；若失败，记录并停止这条优化分支，避免无限调参。
