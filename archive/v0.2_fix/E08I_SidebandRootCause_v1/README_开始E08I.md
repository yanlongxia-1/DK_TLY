# E08-I：动态边带超限与低K收敛的根因实验（开发阶段）

## 为什么做这个实验

E08-H共24个训练MVMD求解，24/24严格收敛，W9-10物理保真12/12通过，Z9-1为0/12。因此**失败不是训练求解器不收敛，而是动态保真检查未通过**。E08-H只保存最小保持率而未保存最大保持率。四个Z9-1候选（K3/4/5 alpha154.158和K3 alpha320）满足已保存的下边界与相位指标，却仍判失败，按原代码说明至少一个频点保持率超出101%。必须找到真实频点、通道和重构环节后再改算法。

此外 E08-H没有检查低K在W9-60上的收敛，因为两训练工况无共同通过候选。所以还**不知道**降低K能否解决W9-60。

## 严格冻结的条件

- 已知滚转9 Hz，fs=1000 Hz，Z9-1载波和8/10Hz边带；原始TXT第4列a，第7列s。
- 收敛 tol=1e-5、未阻尼中心目标差<0.01Hz、连续3次；eta=1；maxIter=2400；AC相对残差<=0.15。
- 双通道幅值保持率99%～101%；单通道和双通道相对相位变化均不超过0.2°。
- **不改K/alpha，不自动选参；这轮是失败根因诊断，不是正式FVIM优化或独立盲测。**

## 真实运行方案（共最多15次联合MVMD求解）

**A：Z9-1 五组既有训练候选**：K3/4/5，alpha154.158；K3和K8，alpha320。每个已收敛解使用同一组模态计算三种重构：

1. `hard_paper`：现有CS＋SampEn＋小波硬分类重构；
2. `all_modes`：全部模态相加，诊断分解本身及AC重构残差；
3. `mixed_without_wavelet`：丢弃类仍丢弃，但混叠类保留未经小波处理的模态。

记录两个通道、8/9/10Hz每一频点原始拟合幅值、保留率、相位变化、相对相位变化、超限标志和IMF分类，区分：**分解残差** vs **分类丢弃** vs **小波处理**。全模态本身也不一定通过物理保真，不能将全模态方案直接当作正式去噪算法。

**B：W9-60 小K收敛检查**：K3～7分别配alpha154.158、320，共10次；维持同样严格tol，不读取编码器角速度，不以此选择K。若收敛，只证明在此已查看难例上有数值可行性，不等于降噪或真实角速度RMSE改善。

## 如何运行

1. 解压后在 `E08I_config.m` 修改 `cfg.dataRoot` 为实际含`Z9-1.TXT`、`W9-60.TXT`的历史TXT目录，支持递归查找。
2. MATLAB当前工作目录切到工程根目录：

```matlab
E08I_selftest
E08I_run
```

3. 程序会在 `results_E08I` 生成：

| 文件 | 作用 |
|---|---|
| `E08I_band_detail.csv` | **最重要：精确的8/9/10Hz双路超限频点，硬重构/全部模态/无小波之间的对照** |
| `E08I_solver.csv` | 15次求解的真实收敛和AC记录，尤其W9-60小K |
| `E08I_mode_classes.csv` | 关键模态中心、能量、CS、SampEn和分类 |
| `E08I_notes.txt` | 固定判据与实验解释 |
| `E08I_issues.csv` | 若读文件或求解异常才生成 |

## 结果决定下一步，而不是无目标重复搜索

- 如果 `all_modes` 在Z9-1达标而 `hard_paper` 不达标：明确是重构分类/小波处理引入了幅相误差，下一步设计双通道物理边带保护重构，并在**训练**数据确定规则。
- 如果 `all_modes` 也不达标：优先分析MVMD求解AC残差在各侧带的投影和边带相位，针对分解层稳定化/约束，不盲目调CS/SampEn。
- 如果 `mixed_without_wavelet` 达标而 `hard_paper` 不达标：小波处理是明确改进对象。
- 如果W9-60部分低K可收敛：只说明较小模态数可能缓解其数值困难，必须再用独立工况检查动态保真；**W9-60已用于开发，不是盲测**。

**所有失败结果原样留存，不因本次看到的验证数据调整99%～101%等原阈值。** 诊断完成才重新设计FVIM适应度和搜索预算，然后进入角速度、俯仰角、偏航角物理精度验证。

静态依赖与文件结构已检查；没有 MATLAB 运行时，真实数值效果必须以本机结果为准。
